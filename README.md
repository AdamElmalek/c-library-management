# Library Management System (C)

A console application in C for managing library members and book loans. Final project for the C programming course at Ruppin Academic Center.

## Features
- Add, delete and search members by ID
- Loan up to 4 books per member and return them
- Detect overdue books by return date
- Sort members by ID and print member reports
- Dynamic memory for names and book titles

## Build & run
```bash
gcc gmar1.c -o library
./library
```
Or open the file in Visual Studio and run.
